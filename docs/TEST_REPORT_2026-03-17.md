## ⚠️ 测试受限项

### 1. 实时行情工具（网络问题）
**测试工具：**
- `stock_quote`
- `index_quote`
- `industry_quote`

**错误信息：**
```
HTTPSConnectionPool(host='48.push2.eastmoney.com', port=443): 
Max retries exceeded - Remote end closed connection without response
```

**原因：** 东方财富 API 服务器暂时不可用（网络波动/限流）

**影响：** 
- 实时行情数据无法获取
- 行业板块数据无法获取
- 指数行情无法获取

** workaround：**
- 回测引擎使用模拟数据，不受影响
- 本地缓存数据仍可使用
- 稍后重试即可恢复
