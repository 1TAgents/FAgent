## 📊 回测指标分类

基于量化投资行业标准（参考 QuantConnect、聚宽、优矿），实现 **6 大类 30+ 个指标**：

### 1️⃣ 收益类指标（6 个）

| 指标 | 英文 | 说明 | 计算方式 |
|------|------|------|----------|
| **总收益率** | Total Return | 整个回测期的总收益 | (最终资金/初始资金 - 1) × 100% |
| **年化收益率** | Annual Return | 年化后的收益率 | [(1+总收益)^(252/n) - 1] × 100% |
| **超额收益率** | Excess Return | 相对基准的超额收益 | 策略年化 - 基准年化 |
| **月均收益率** | Monthly Return | 平均每月收益 | 年化收益 / 12 |
| **最佳月度收益** | Best Month | 表现最好的月份 | max(月度收益) |
| **最差月度收益** | Worst Month | 表现最差的月份 | min(月度收益) |

**行业标准：**
- ✅ 优秀策略：年化 > 15%，月均 > 1%
- ⚠️ 注意：区分牛市/熊市表现

---

### 2️⃣ 风险类指标（7 个）

| 指标 | 英文 | 说明 | 计算方式 |
|------|------|------|----------|
| **波动率** | Volatility | 收益的波动程度 | Std(日收益) × √252 |
| **下行波动率** | Downside Volatility | 仅计算亏损的波动 | Std(负收益) × √252 |
| **最大回撤** | Max Drawdown | 历史最大亏损幅度 | (峰值 - 谷值) / 峰值 |
| **平均回撤** | Average Drawdown | 平均亏损幅度 | Mean(所有回撤) |
| **回撤持续期** | Drawdown Duration | 最大回撤的天数 | 从峰值到恢复的天数 |
| **VaR(95%)** | Value at Risk | 95% 置信度的最大损失 | 5% 分位数 |
| **CVaR(95%)** | Conditional VaR | 超过 VaR 的平均损失 | 尾部期望损失 |

**行业标准：**
- ✅ 优秀策略：最大回撤 < 15%，波动率 < 20%
- ⚠️ 警戒：最大回撤 > 30%

### 3️⃣ 风险调整收益指标（5 个）

| 指标 | 英文 | 说明 | 计算方式 | 优秀标准 |
|------|------|------|----------|----------|
| **夏普比率** | Sharpe Ratio | 单位风险的超额收益 | (年化 - 无风险) / 波动率 | > 1.0 |
| **索提诺比率** | Sortino Ratio | 仅考虑下行风险 | (年化 - 无风险) / 下行波动率 | > 1.5 |
| **卡玛比率** | Calmar Ratio | 收益/最大回撤 | 年化 / |最大回撤| | > 2.0 |
| **欧米伽比率** | Omega Ratio | 收益/损失比 | 正收益和 / |负收益和| | > 1.5 |
| **信息比率** | Information Ratio | 相对基准的稳定性 | 超额收益 / 跟踪误差 | > 0.5 |

**行业标准：**
- 🏆 夏普 > 1.0：良好
- 🏆 夏普 > 2.0：优秀
- 🏆 夏普 > 3.0：卓越

### 4️⃣ 交易统计指标（10 个）

| 指标 | 英文 | 说明 | 计算方式 |
|------|------|------|----------|
| **总交易次数** | Total Trades | 总交易笔数 | Count(交易) |
| **盈利次数** | Winning Trades | 盈利交易数量 | Count(盈利 > 0) |
| **亏损次数** | Losing Trades | 亏损交易数量 | Count(盈利 < 0) |
| **胜率** | Win Rate | 盈利比例 | 盈利次数 / 总次数 |
| **盈亏比** | Profit Factor | 平均盈利/平均亏损 | 总盈利 / |总亏损| |
| **平均盈利** | Average Win | 平均每笔盈利 | Mean(盈利交易) |
| **平均亏损** | Average Loss | 平均每笔亏损 | Mean(亏损交易) |
| **平均每笔收益** | Avg Trade Return | 所有交易平均 | Mean(所有交易) |
| **平均持仓天数** | Avg Holding Days | 平均持仓时间 | Mean(持仓天数) |
| **最大连胜** | Max Consecutive Wins | 最长连续盈利 | Max(连续盈利次数) |
| **最大连亏** | Max Consecutive Losses | 最长连续亏损 | Max(连续亏损次数) |

**行业标准：**
- ✅ 胜率 > 50%：良好
- ✅ 盈亏比 > 2.0：优秀（赚大赔小）
- ⚠️ 警惕：胜率 > 80% 可能过拟合

### 6️⃣ 基准对比指标（5 个）

| 指标 | 英文 | 说明 | 计算方式 |
|------|------|------|----------|
| **基准收益率** | Benchmark Return | 对标指数收益 | 如沪深 300 收益 |
| **Alpha** | Alpha | 超额收益 | 策略收益 - Beta × 基准收益 |
| **Beta** | Beta | 市场敏感度 | Cov(策略，市场) / Var(市场) |
| **相关系数** | Correlation | 与基准的相关性 | Corr(策略收益，基准收益) |
| **跟踪误差** | Tracking Error | 偏离基准的程度 | Std(策略 - 基准) |

**行业标准：**
- ✅ 优秀策略：Alpha > 0，Beta 接近 1
- 🎯 市场中性：Beta ≈ 0

## 🎯 核心指标解读

### 夏普比率 (Sharpe Ratio)

**公式：**
```
Sharpe = (Rp - Rf) / σp
```

- Rp：策略年化收益率
- Rf：无风险利率（通常取 3%）
- σp：策略年化波动率

**解读：**
- < 0：策略不如无风险收益 ❌
- 0-1：收益勉强覆盖风险 ⚠️
- 1-2：良好 ✅
- 2-3：优秀 🏆
- > 3：卓越（警惕过拟合）⚠️

---

### 最大回撤 (Max Drawdown)

**公式：**
```
MaxDD = max[(峰值 - 谷值) / 峰值]
```

**解读：**
- < 10%：风险控制优秀 ✅
- 10-20%：正常范围 ✅
- 20-30%：风险较高 ⚠️
- > 30%：风险过高 ❌

**心理阈值：**
- 大多数投资者能承受的最大回撤约 20-25%

---

### 胜率 vs 盈亏比

**关系：**
```
期望值 = 胜率 × 平均盈利 - (1 - 胜率) × 平均亏损
```

**典型组合：**
1. **高胜率 + 低盈亏比**（如 70% 胜率，1.2 盈亏比）
   - 适合：短线交易、做市策略
   - 风险：一次大亏可能抹去多次盈利

2. **低胜率 + 高盈亏比**（如 40% 胜率，3.0 盈亏比）
   - 适合：趋势跟踪、长线策略
   - 优势：亏小赚大

**最佳实践：**
- ✅ 胜率 > 45% 且 盈亏比 > 2.0
- ✅ 胜率 > 55% 且 盈亏比 > 1.5

## 🔧 使用示例

### 完整回测流程

```python
from agents.backtest.data_loader import get_data_loader
from agents.backtest.vectorized_strategies import get_vectorized_strategy
from agents.backtest.performance_metrics import MetricsCalculator

# 1. 加载数据
data = get_data_loader().load_klines("600519", "2025-01-01", "2025-12-31")

# 2. 选择策略
strategy = get_vectorized_strategy('macd')
signals = strategy.generate_signals(data)

# 3. 执行回测
result = strategy.backtest(signals, 100000)

# 4. 计算指标
calculator = MetricsCalculator(risk_free_rate=0.03)
metrics = calculator.calculate_all_metrics(
    equity_curve=result['equity_curve'],
    daily_returns=result['daily_returns'],
    trades=result['trades']
)

# 5. 查看结果
print(f"总收益：{metrics.total_return:.2f}%")
print(f"夏普比率：{metrics.sharpe_ratio:.2f}")
print(f"最大回撤：{metrics.max_drawdown:.2f}%")
print(f"胜率：{metrics.win_rate:.1f}%")
```

## 📝 总结

### 指标体系特点

1. ✅ **完整性**：6 大类 30+ 个指标
2. ✅ **标准化**：符合行业最佳实践
3. ✅ **可解释性**：每个指标都有明确含义
4. ✅ **实用性**：支持策略对比和评级

### 关键要点

1. **不要单一指标决策**
   - 夏普高 + 回撤大 = 高风险
   - 胜率高 + 盈亏比低 = 一次大亏回到解放前

2. **关注风险调整收益**
   - 夏普比率 > 1.0
   - 卡玛比率 > 2.0

3. **重视最大回撤**
   - 历史最大回撤 < 25%
   - 考虑心理承受能力

4. **长期稳定性**
   - 至少 3-5 年回测数据
   - 跨越牛熊周期
