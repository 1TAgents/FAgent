# 数据同步服务

## 稳定免费数据源对比

| 数据源 | 优点 | 缺点 | 稳定性 | 推荐度 |
|--------|------|------|--------|--------|
| **AKShare** | 完全免费、无需注册、数据全 | 依赖东方财富/新浪等，偶尔网络波动 | ⭐⭐⭐⭐ | ✅ **主力** |
| **Tushare** | 数据稳定、接口规范 | 免费积分有限，高频数据需付费 | ⭐⭐⭐⭐⭐ | ⭐ 备用 |
| **Baostock** | 完全免费、无需积分 | 数据更新慢、文档旧 | ⭐⭐⭐ | ⭐ 备用 |
| **Sina API** | 速度快、稳定 | 非官方、可能变更 | ⭐⭐⭐⭐ | ✅ 补充 |

## 推荐方案

**主数据源：AKShare**（新浪 + 东财数据）
- 完全免费，社区活跃维护
- 覆盖 A 股、指数、行业、基金、期货等
- 即使偶尔波动，重试即可恢复

**备用方案：**
1. 本地缓存优先（SQLite + Redis）
2. 失败时自动重试（指数退避）
3. 多数据源 fallback（新浪→东财→百度）

## 数据同步策略

### 1. 全量同步（低频）

| 数据类型 | 频率 | 时间 | 数据量估算 |
|----------|------|------|------------|
| 股票列表 | 每周六 02:00 | 5 分钟 | ~5000 只 × 1KB = 5MB |
| 指数列表 | 每周六 02:05 | 1 分钟 | ~500 只 × 1KB = 0.5MB |
| 行业列表 | 每周六 02:06 | 1 分钟 | ~100 只 × 1KB = 0.1MB |

### 2. 增量同步（高频）

| 数据类型 | 频率 | 时间 | 数据量估算 |
|----------|------|------|------------|
| 当日 K 线 | 交易日 15:30 | 30 分钟 | 5000 只 × 0.5KB = 2.5MB/天 |
| 实时行情 | 按需 | - | 缓存 60 秒 |
| 指数行情 | 按需 | - | 缓存 60 秒 |

### 3. 历史数据补全（后台持续）

**策略：**
- 优先级：热门股票（沪深 300）> 其他股票
- 速度：1 只股票/秒（避免触发限流）
- 数据量：1 只股票 10 年日线 ≈ 2500 条 × 0.1KB = 0.25MB
- 总容量：5000 只 × 0.25MB = **1.25GB**（10 年日线）

**预计时间：**
- 每天同步 100 只股票的历史数据
- 50 天完成全量 A 股历史数据缓存
- 10G 容量可存储约 **40 年** 全量 A 股日线数据

## 启动命令

```bash
# 启动数据同步服务（后台运行）
cd <repo-root>
PYTHONPATH=. python3 -m uvicorn agents.data_sync.service:app --reload --port 8003

# 查看同步状态
curl http://localhost:8003/status

# 手动触发同步
curl -X POST http://localhost:8003/sync/stocks
curl -X POST http://localhost:8003/sync/klines?symbol=600519
```

## 数据量控制

```python
# 配置示例
MAX_DB_SIZE_GB = 10  # 数据库最大 10GB
SYNC_SPEED_PER_SEC = 1  # 每秒同步 1 只股票
DAILY_SYNC_COUNT = 100  # 每天同步 100 只股票历史
```
